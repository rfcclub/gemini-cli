# Handoff Archive

Historical handoff notes from Vesta sessions, archived here so they remain
discoverable without polluting the repository root.

## Convention

- **Active handoff** lives at the repo root: `HANDOFF_<YYYY-MM-DD>.md` (it is
  the most recent working artifact and is intentionally easy to find).
- **Archived handoffs** are moved here once superseded.
- Each handoff is named after the session date, not the session topic.
- Read the most recent handoff first to understand the current branch state.

## Why archived

The root-level handoff was getting out of hand:

- Multiple handoff files cluttered the repo root.
- Stale handoffs caused confusion when picking up a new session.

This directory preserves the historical record while keeping the root clean.
