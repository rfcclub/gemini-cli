## Lessons learned (for future Vesta)

1. **LoomKit verify reads `.traceability.yaml`**, not test names. Mapping must
   be manual.
2. **Scenario IDs are slugified** `reqTitle + scTitle` (kebab-case). Match
   exactly or coverage 0%.
3. **Function declarations inside arrow function callbacks** don't hoist
   properly with TS strict mode. Use `const arrow = () =>` instead.
4. **`vi.resetAllMocks()`** in parent `beforeEach` wipes inner mocks — must
   re-set in test body.
5. **Promise microtask ordering in tests** — `replaceRangeByOffset` runs in
   fire-and-forget async; need explicit `await new Promise(setTimeout)` to flush
   before assertions.
6. **Buffer mocks don't auto-update `.text`** — `replaceRangeByOffset` is
   `vi.fn()` so `mockBuffer.text` stays stale. Tests that need buffer state must
   update manually or inspect call args directly.
